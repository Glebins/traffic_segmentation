# Traffic Segmentation

## О проекте

**Traffic Segmentation** — это комплексное решение для анализа сетевого трафика, детектирования угроз и визуального мониторинга. Проект сочетает перехват пакетов на уровне системы, аналитику посредством алгоритмов машинного обучения с учителем и без, а также интерфейс для просмотра результатов.

Проект выполняет следующие задачи:
- перехватывает и анализирует сетевые пакеты в реальном времени;
- классифицирует трафик на нормальный и вредоносный;
- использует машинное обучение для обнаружения аномалий;
- генерирует оповещения при подозрительной активности;
- предоставляет визуальный интерфейс для мониторинга и управления.

## Основные компоненты

- `main.py` — основной исполняемый файл. Запускает сбор трафика, вызывает движок захвата и передаёт поток данных на анализ.
- `threat_analysis.py` — модуль анализа угроз и гибридная система классификации. Объединяет XGBoost, Autoencoder, Isolation Forest, LOF и мета-модель.
- `gui.py` — графический интерфейс. Читает лог-файл и отображает данные в таблице, обновляет представление примерно раз в секунду.
- `addons/EtwTcp/` — проект на C#. Собирает сетевую телеметрию через ETW и передаёт данные в основной пайп.

## Архитектура анализа

Система поддерживает несколько методов классификации и детекции:
- XGBoost — основной классификатор для трафика;
- гибридный анализ безопасности на основе ансамблей;
- Isolation Forest — обнаружение аномалий;
- Local Outlier Factor (LOF) — локальный фактор выбросов;
- Autoencoder — глубокое обучение для выявления отклонений.

### Результаты анализа

Результаты сохраняются в `flow_log_test.csv` и содержат следующие поля:

| Поле | Описание |
|------|----------|
| `ts` | временная метка в UTC |
| `PID` | идентификатор процесса |
| `process` | имя процесса |
| `num_of_packets` | количество пакетов в потоке |
| `threat probability` | вероятность угрозы |
| `status` | статус (`CRITICAL`, `HIGH`, `WARNING`, `ACCUMULATION`) |
| `xgb_score` | уверенность XGBoost |
| `xgb_label` | классификация (`Normal`, `DoS`, `DDoS`, `Bots`, `Port Scanning`, `Brute Force`, `Web Attacks`) |
| `anomaly_score` | консенсус аномалии |

### Признаки и модели

Для анализа используются более 50 признаков потоков, включая:
- статистику пакетов: размер, направление, скорость;
- межпакетные интервалы (IAT);
- информацию о портах и протоколах;
- активные и простаивающие периоды.

## Мониторинг и интерфейс

### GUI

Запуск:
```bash
python gui.py
```

Функциональность интерфейса:
- просмотр последних потоков в реальном времени (до 150 записей);
- фильтрация по PID, процессу и статусу;
- цветовое выделение по уровню угрозы;
- обновление таблицы раз в секунду;
- запуск обучения моделей прямо из интерфейса;
- копирование данных из таблицы.

## Режимы работы

### Режим активной работы

Система анализирует трафик в реальном времени и выдает категорию сетевого потока на основе обученных моделей.

### Режим накопления данных

В этом режиме проект накапливает признаки потоков для последующего обучения. При включённом режиме накопления данные сохраняются в `flow_features_test.csv`, а функция классификации отключена.

## Быстрый старт

1. Клонируйте репозиторий.
2. Установите зависимости Python и .NET SDK. Для Python используйте `requirements.txt`:
   ```bash
   python -m pip install -r requirements.txt
   ```
3. Скомпилируйте C#-проект из `addons/EtwTcp/`:
   - перейдите в папку `addons/EtwTcp/`;
   - выполните:
     ```bash
     dotnet publish -c Release -r win-x64 --self-contained false
     ```
   - используйте `addons/EtwTcp/bin/Release/net7.0/win-x64/EtwTcp.exe`.
4. По умолчанию в `main.py` задан путь `ENGINE_PATH = "./publish/EtwTcp.exe"`.
   - поместите собранный `EtwTcp.exe` в `publish/` рядом с `main.py` или измените `ENGINE_PATH`.
5. Запустите `main.py` как основной процесс. Он сам запустит `EtwTcp.exe` и начнёт сбор трафика.
6. Запустите `gui.py` параллельно для визуального мониторинга. Интерфейс читает лог-файл и обновляет данные раз в секунду.
